# Visualizador de Métodos de Array

Ferramenta interativa desenvolvida em JavaScript puro para visualizar, na prática, o comportamento e os retornos dos principais métodos de iteração de arrays (`.map()`, `.filter()` e `.find()`).

## Funcionalidades

- **Visualização em tempo real:** Renderização dinâmica dos elementos no DOM a cada transformação aplicada.
- **Indicador de expressão:** Exibição da sintaxe exata executada na operação atual.
- **Cards explicativos:** Resumo contextual sobre o funcionamento e o tipo de retorno de cada método, alimentado por estrutura de objeto literal.
- **Controle de estado centralizado:** Gerenciamento unificado de visibilidade dos controles e retorno ao estado original (`Reset`) sem mutar o array base.

## Tecnologias

- HTML5 semântico
- CSS3 (Flexbox, Custom Properties, `@keyframes`)
- JavaScript ES6+ (Manipulação de DOM, Métodos de Array, Objetos Literais)

## Como executar

Clone o repositório e abra o arquivo `index.html` diretamente no navegador ou via extensão Live Server no VS Code.
